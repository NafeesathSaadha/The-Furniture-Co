# The Furniture Co

## Overview

**The Furniture Co** is a concept furniture e-commerce website developed as a front-end project. The website showcases a variety of aesthetic wooden furniture items and demonstrates the basic structure of an online furniture store.

This project was created to practice web development fundamentals and to understand how multi-page websites are structured and organized.

---

## Features

* Multiple furniture categories
* Product browsing pages
* Wishlist page
* Shopping cart page
* Login page
* Contact and About pages
* Simple and clean user interface

---

## Furniture Categories

The website includes separate pages for different furniture types such as:

* Chairs
* Tables
* Bookshelves
* Mirrors
* Corner Stands
* Shoe Racks

Each page displays furniture items in an organized layout.
